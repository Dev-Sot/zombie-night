# Roadmap

Plan de desarrollo por fases. Cada fase se cierra con un release desplegado
en Vercel antes de pasar a la siguiente.

## Fase 0 — Base ✅
- [x] Prototipo jugable: movimiento, disparo, oleadas, linterna, HUD.
- [x] Despliegue en Vercel.

## Fase 1 — Mecánicas core
- [ ] Colisión con props (autos/cajas bloquean el paso, sirven de cobertura).
- [ ] Segundo superviviente jugable (pantalla de selección de personaje).
- [ ] Segunda arma (escopeta o cuchillo cuerpo a cuerpo), cambio con 1/2/3.
- [ ] Perks entre oleadas (elegir 1 de 2-3 mejoras al limpiar cada oleada).

## Fase 2 — Contenido y progresión
- [ ] Niveles/mapas distintos (no solo una arena infinita).
- [ ] Nuevos tipos de zombie / jefes de oleada.
- [ ] Historial de partidas (además del mejor récord guardado).

## Fase 3 — Accesibilidad
- [ ] Controles táctiles para móvil (joystick virtual + disparo con
      auto-apuntado).
- [ ] Menú de opciones (volumen, dificultad).

## Fase 4 — Arte y atmósfera
- [ ] Mejoras visuales de personajes/zombies (basadas en referencias).
- [ ] Más variedad de props y ambientación.
- [ ] Efectos de partículas e iluminación adicionales.
- [ ] Evaluar samples de sonido reales (licencia libre) en vez de sintetizado.

## Fase 5 — Multijugador
- [ ] Definir arquitectura (co-op local primero, luego online si aplica).
- [ ] Prototipo de sesión compartida.

---

Las referencias visuales (Pinterest, otros juegos, etc.) se agregan como
issues o se discuten antes de empezar cada fase, para no romper el estilo ya
definido en el juego.
